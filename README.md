## What is AIC?

Australia introduces AI Agent Studio but no governance automation.

AIC scans `sn_ai_agent` and enforces:
- BYOK provider required
- Log retention ≥ 90 days
- Human-in-the-loop for critical confidence
- MCP rate limits defined
